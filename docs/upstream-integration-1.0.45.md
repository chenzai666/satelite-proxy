# 上游 v1.0.45 整合记录

比较上游正式版 v1.0.44 至 v1.0.45（12d66fa16ed5c43edd5f474e404782b747e3ffc4）。功能提交为 19dc51f；逐处适配本分支，不整文件覆盖。

## 合入内容

- Clash 节点保存原始 YAML，Mihomo 生成时保留模型未覆盖的参数；SSR、mieru 可作为原文节点导入。其他内核不能因此获得原生协议支持。
- 订阅菜单增加原始配置查看、复制及内核支持详情。报告基于保存的订阅原文，不代表手动编辑后的节点或多内核委托结果。
- 完整自定义配置识别 sing-box JSON、Mihomo YAML、Xray JSON，使用对应内核启动；旧 sing-box 配置兼容读取。
- 配置类型标签、自定义配置文案、弹窗底部留白。
- 应用及 Windows 构建、发布版本同步为 1.0.45。

## 本分支适配

- 保留当前配置粘贴、clone、本地编辑覆盖、拖拽排序、原生 Mihomo 分组规则及 AnyTLS/TUIC 手动选择回退。
- 已建模节点经表单编辑后使用编辑结果，不再用旧原文覆盖；原文类型暂不提供不完整的表单编辑。
- 原文代理链按原始名称重写引用，改名不破坏引用；重名歧义不随意选择，循环及悬空依赖拒绝生成。
- 保留显式 DIRECT 出站及 IPv4/DNS、UWP 和系统代理定制；UDP TLS 兼容选项同步到原文副本，默认不放宽证书校验。
- SOCKS-only 自定义配置不被当作 HTTP 系统代理端口；自定义配置开启系统代理失败时停止内核并返回错误。
- 节点列表不传输原文，减少 IPC 数据量；原始配置保存在应用数据目录 subscriptions 下，包含凭据，禁止公开分享。

## 未整合的历史差异

同 URL 多订阅与上游节点身份迁移继续暂缓，避免覆盖本分支节点 ID、本地副本及规则引用。

## 验证边界

本地仅类型检查、Node 回归和 Rust 语法检查；Rust 单测及 Windows 安装包构建交给 GitHub Actions。自定义配置按原文运行，不自动重写其路由、DNS、监听与安全设置；仅导入可信配置。实际三内核网络和提权行为还需实机验证。
