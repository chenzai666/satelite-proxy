## DNS 修复边界

- Mihomo 不再生成跨池 fallback；nameserver 仅使用用户选择的默认池。
- Xray 的其他池仅服务显式分类，使用 skipFallback；Local 分类不会再因默认选择远程而丢失。
- 旧 leak_protect 字段保留反序列化兼容，但不再关闭回退保护；已移除无效开关。
- 国内解析、节点域名引导解析仍允许按配置直连，不承诺系统级零 DNS 泄露。
- sing-box 保留本分支 direct_resolver、IPv4 和旧内核兼容逻辑，只将国内地址改用共享常量。
- Mihomo 的订阅原生策略组、规则优先级、模式选择和本分支直连出口不被上游生成器覆盖。

## 主动保留的差异

不恢复赞助入口、系统代理绕过/TUN 提示；不引入第三方内核下载镜像、
仓库内 geodata 二进制快照或强制三内核捆绑。保留 Windows 安装版和便携版。

## 验证

本地仅安装前端依赖、运行类型检查、脚本语法与源码检查，不编译客户端。
Windows 编译、安装包、便携包与 Rust 单元测试由 GitHub Actions 执行。
macOS 修改来自对应上游实现，但仍需要 macOS 实机授权/打包验证。
本次不修改本地安装目录、订阅、系统代理或正在运行的内核。
