# Satelite 1.0.45

## 本次更新

- 整合上游 1.0.45：Mihomo 保留 Clash 节点原始参数，支持 SSR、mieru 原文节点，不再仅依赖通用模型重建。
- 订阅菜单新增“查看配置”和“内核支持”，可查看各内核原生支持数量及解析跳过原因。支持报告针对订阅原文，不等于多内核自动回退结果。
- 完整自定义配置可识别并启动 sing-box、Mihomo、Xray；旧版 sing-box 配置继续兼容。
- 保留本分支原生订阅策略组、IPv4/DNS、UWP、节点拖拽及复制粘贴等定制。
- 修复移植过程中的原文发射、手动编辑和代理链名称一致性；循环和悬空代理链拒绝生成。
- 自定义配置只有 SOCKS 入站时，不错误设置 HTTP 系统代理；增加配置类型标签和弹窗留白。

## 升级注意

升级前备份配置。原始配置含节点密码、订阅信息，不要公开上传。自定义配置按原文运行，需要自行审查监听地址、控制接口、规则和 DNS；它不自动套用应用生成配置的安全开关。

Windows 安装包和便携包只在 GitHub Actions 测试、构建成功后发布。本地客户端不随源码整合自动替换；实际网络及跨平台行为不以静态检查替代。
