# 立体毛玻璃导航栏实现技术说明

## 1. 目标

实现一种具有明显玻璃材质感的悬浮导航栏，视觉特征包括：

* 半透明深色玻璃主体
* 导航栏后方内容实时模糊
* 左上角存在明显受光高光
* 顶部边缘略亮
* 底部与右侧略暗
* 具有一定玻璃厚度和悬浮感
* 页面滚动后提高导航栏可读性
* 背景颜色仍可透过玻璃保留一定色彩

核心效果主要由以下几部分组成：

1. `backdrop-filter`
2. 半透明背景
3. 方向性高光
4. 边缘高光
5. 内外阴影
6. 页面背景光源
7. 滚动状态切换

---

# 2. DOM 结构

推荐结构：

```html
<div class="nav-wrap">
  <nav class="glass-nav" id="glassNav">
    <div class="glass-rim"></div>

    <div class="brand">
      Swift Glass
    </div>

    <div class="nav-links">
      <a href="#">Features</a>
      <a href="#">Screens</a>
      <a href="#">Protocols</a>
      <a href="#">Privacy</a>
    </div>

    <a class="nav-button" href="#">
      Download
    </a>
  </nav>
</div>
```

其中：

```text
nav-wrap
    │
    └── glass-nav
            │
            ├── glass-rim
            ├── brand
            ├── nav-links
            └── nav-button
```

`glass-nav` 负责玻璃主体。

`::before` 负责表面反射。

`::after` 负责左上角光源。

`glass-rim` 负责内部边缘厚度。

# 3. 悬浮导航布局

```css
.nav-wrap {
  position: fixed;

  top: 18px;
  left: 0;
  right: 0;

  z-index: 1000;

  display: flex;
  justify-content: center;

  padding: 0 20px;

  pointer-events: none;
}
```

导航主体：

```css
.glass-nav {
  width: min(980px, 100%);
  height: 64px;

  padding: 0 10px 0 20px;

  display: flex;
  align-items: center;

  gap: 28px;

  pointer-events: auto;
}
```

推荐保持导航栏和浏览器顶部约：

```text
16px ~ 20px
```

距离。

这样可以形成独立悬浮组件的视觉效果。

# 4. 毛玻璃核心实现

关键属性：

```css
.glass-nav {
  background: rgba(18, 18, 20, 0.56);

  -webkit-backdrop-filter:
    blur(20px)
    saturate(142%)
    brightness(0.96);

  backdrop-filter:
    blur(20px)
    saturate(142%)
    brightness(0.96);
}
```

其中：

## blur

```css
blur(20px)
```

负责模糊导航栏后方的页面内容。

推荐范围：

```text
16px ~ 24px
```

20px 左右适合桌面端悬浮导航。

---

## saturate

```css
saturate(142%)
```

作用是保留背景中的色彩。

如果只使用：

```css
blur(20px)
```

背景颜色很容易被模糊成灰色。

增加：

```css
saturate(130% ~ 150%)
```

后，背景图片、渐变和光晕经过导航栏时会更加鲜活。

---

## brightness

```css
brightness(0.96)
```

轻微降低玻璃后方内容亮度。

作用是提高：

```text
导航文字
按钮
Logo
```

的对比度。

建议范围：

```text
0.92 ~ 1.0
```

---

# 5. 玻璃主体背景

可以使用单纯 RGBA：

```css
background:
  rgba(18, 18, 20, 0.56);
```

如果希望材质更有厚度，可以加入垂直渐变：

```css
background:
  linear-gradient(
    180deg,
    rgba(31, 33, 39, 0.62) 0%,
    rgba(18, 19, 23, 0.56) 48%,
    rgba(13, 14, 18, 0.58) 100%
  );
```

这样顶部稍亮，底部稍暗。

能够模拟玻璃表面在光照下产生的轻微明暗变化。

建议避免上下反差过大。

整个导航仍然需要保持：

```text
透明
柔和
克制
```

---

# 6. 基础玻璃边框

```css
.glass-nav {
  border:
    1px solid rgba(255, 255, 255, 0.075);

  border-radius: 19px;
}
```

推荐透明度：

```text
0.06 ~ 0.10
```

边框过亮会产生明显卡片感。

---

# 7. 左上角局部白边

这是整个效果中非常重要的一部分。

普通统一边框无法形成明显的光源方向。

因此使用 `::before` 增加局部反射：

```css
.glass-nav::before {
  content: "";

  position: absolute;
  inset: 0;

  border-radius: inherit;

  pointer-events: none;

  background:
    linear-gradient(
      135deg,

      rgba(255,255,255,.26) 0%,

      rgba(255,255,255,.13) 5%,

      rgba(255,255,255,.055) 13%,

      rgba(255,255,255,.018) 23%,

      rgba(255,255,255,0) 39%
    );
}
```

这里的：

```css
135deg
```

代表光线主要集中在左上角。

视觉效果：

```text
亮
╲
 ╲
  ╲
   暗
```

左上区域反射最强。

逐渐向右下消失。

---

# 8. 顶部整体反光

可以继续在 `::before` 中增加第二层渐变：

```css
background:

  linear-gradient(
    135deg,
    rgba(255,255,255,.26),
    rgba(255,255,255,0) 39%
  ),

  linear-gradient(
    180deg,
    rgba(255,255,255,.065) 0%,
    rgba(255,255,255,.018) 28%,
    rgba(255,255,255,0) 62%
  );
```

第二层负责顶部整体轻微发亮。

因此会形成：

```text
左上角：高亮
顶部：微亮
右侧：正常
底部：偏暗
```

材质方向会更加明确。

---

# 9. 左上角光源

在 `::after` 中增加柔光。

```css
.glass-nav::after {
  content: "";

  position: absolute;

  width: 260px;
  height: 116px;

  top: -56px;
  left: -6px;

  border-radius: 50%;

  pointer-events: none;

  background:
    radial-gradient(
      ellipse at center,

      rgba(255,255,255,.24) 0%,

      rgba(255,255,255,.13) 28%,

      rgba(255,255,255,.055) 48%,

      rgba(255,255,255,0) 73%
    );

  filter: blur(13px);

  opacity: .9;
}
```

这个元素可以理解成：

```text
      光源
        ↓

     ●●●●
   ●●●●●●
 ┌───────────┐
 │ glass nav │
 └───────────┘
```

光源本身位于导航栏外部。

只有柔和的余光落在玻璃表面。

因此不会出现明显的白色斑块。

# 10. 内部边缘厚度

额外增加一个内层：

```html
<div class="glass-rim"></div>
```

CSS：

```css
.glass-rim {
  position: absolute;

  inset: 1px;

  border-radius: 18px;

  pointer-events: none;

  box-shadow:
    inset 1px 1px 0
      rgba(255,255,255,.07),

    inset -1px -1px 0
      rgba(0,0,0,.16);
}
```

作用是模拟：

```text
左上内边缘 → 亮

右下内边缘 → 暗
```

因此能够产生类似：

```text
玻璃厚度
倒角
边缘折射
```

的效果。

---

# 11. 外部阴影

基础阴影：

```css
.glass-nav {
  box-shadow:

    0 18px 52px rgba(0,0,0,.30),

    0 4px 14px rgba(0,0,0,.16),

    inset 0 1px 0
      rgba(255,255,255,.10),

    inset 0 -1px 0
      rgba(255,255,255,.018);
}
```

这里实际包含四层：

```text
第一层
大范围悬浮阴影

第二层
靠近导航栏的接触阴影

第三层
顶部内部高光

第四层
底部内部边缘
```

视觉关系：

```text
       高光
  ┌─────────────┐
  │             │
  │    glass    │
  │             │
  └─────────────┘
       暗边

       ↓

    soft shadow
```

# 12. 页面背景非常重要

`backdrop-filter` 的效果依赖导航栏后方内容。

如果页面背景为：

```css
background: #111;
```

即使使用：

```css
blur(30px)
```

视觉效果也不会明显。

推荐使用：

```css
body {
  background:

    radial-gradient(
      circle at 14% 2%,
      rgba(255,255,255,.065),
      transparent 15%
    ),

    radial-gradient(
      circle at 20% 5%,
      rgba(105,120,255,.28),
      transparent 26%
    ),

    radial-gradient(
      circle at 78% 12%,
      rgba(40,205,175,.14),
      transparent 25%
    ),

    linear-gradient(
      180deg,
      #0e1118,
      #090b0f
    );
}
```

导航栏后方需要有：

```text
颜色
亮度变化
图片
渐变
光晕
文字
卡片
```

毛玻璃效果才能充分表现。

# 13. 滚动状态

页面顶部可以保持较高透明度。

当用户开始滚动后，提高玻璃密度：

```css
.glass-nav.scrolled {
  background:
    linear-gradient(
      180deg,

      rgba(32,34,39,.70),

      rgba(17,18,22,.66) 52%,

      rgba(12,13,16,.69)
    );

  -webkit-backdrop-filter:
    blur(24px)
    saturate(148%)
    brightness(.94);

  backdrop-filter:
    blur(24px)
    saturate(148%)
    brightness(.94);

  box-shadow:
    0 22px 60px rgba(0,0,0,.34),
    0 5px 16px rgba(0,0,0,.18),
    inset 0 1px 0 rgba(255,255,255,.11);

  transform: translateY(-1px);
}
```

JS：

```js
const nav =
  document.getElementById("glassNav");

function updateNav() {
  nav.classList.toggle(
    "scrolled",
    window.scrollY > 20
  );
}

updateNav();

window.addEventListener(
  "scroll",
  updateNav,
  {
    passive: true
  }
);
```

# 14. 动画

建议使用 250ms～300ms 的缓慢动画：

```css
.glass-nav {
  transition:

    transform .28s ease,

    background .28s ease,

    box-shadow .28s ease,

    border-color .28s ease,

    backdrop-filter .28s ease,

    -webkit-backdrop-filter .28s ease;
}
```

不推荐使用过强的：

```text
spring
bounce
elastic
```

玻璃材质适合缓慢、稳定的状态变化。

# 17. 性能注意事项

`backdrop-filter` 会增加 GPU 合成成本。

建议控制使用范围。

例如只在：

```text
导航栏
浮层
少量卡片
```

使用。

避免整个页面大量组件同时使用：

```css
backdrop-filter: blur(...)
```

尤其避免：

```text
几十个列表项
大量动态元素
全屏 Blur
```

同时存在。

---

# 18. Safari 兼容

需要同时保留：

```css
-webkit-backdrop-filter:
  blur(20px)
  saturate(142%);

backdrop-filter:
  blur(20px)
  saturate(142%);
```

否则部分 Safari 环境可能无法正常显示。

---

# 19. 降级方案

如果浏览器不支持 `backdrop-filter`：

```css
@supports not (
  backdrop-filter: blur(10px)
) {

  .glass-nav {
    background:
      rgba(20,21,24,.94);
  }

}
```

这样至少能够保持导航栏可读性。
