# Satelite 1.0.46

本版本继续整合上游正式版 1.0.46，并保留本分支的系统代理、DNS/IPv4、UWP、原生 Mihomo 分流与节点交互定制。

## 本次更新

### 2026-10-10 同版本修复

- 更新订阅时替换旧的订阅节点并按新订阅原顺序排列，不把新增订阅节点因旧排序记录而堆到列表末尾；其他配置的相对排序不变。手动拖拽仍可使用，下一次更新订阅恢复订阅顺序。
- 手动添加、粘贴到当前配置的节点（包括 clone）保留，放在订阅节点之后；它们的名称和参数不会被订阅刷新覆盖。
- 同配置、同协议且两侧原始名称唯一的节点，在订阅轮换地址、端口或凭据时沿用原节点 ID，保留选中状态与收藏；重名歧义不强行合并，不匹配到其他配置或手动 clone。
- 本次修复后开始的本地编辑记录编辑前参数，刷新仅保留实际手改字段，未修改的密码、地址等跟随订阅更新；改名不冻结整份旧连接参数。旧版本完整覆盖记录缺少可信基线，仍保守保留，避免误删手动修改。
- 节点页支持 Delete 删除已选节点、Ctrl+A 后批量删除，继续弹窗确认；取消不删除，输入框、弹窗、只读自写配置与长按均不误触发。
- 增加订阅刷新/持久化 Rust 回归、快捷键单测和真实节点页面的隔离浏览器删除测试。版本保持 1.0.46，验证成功后覆盖原 Release 安装包与便携包。

### 上游整合与原有优化

- 节点分组标题增加“真实延迟”和“TCP Ping”按钮，仅测试当前分组；列表与卡片视图均可使用。单组重测不会清除其他组的不支持标记。
- 节点列表增加独立订阅列，节点名与订阅名分开显示；保留最小列宽与横向滚动。
- Clash OpenVPN 条目保留原始参数导入，交给支持该协议的 Mihomo 内核；使用 sing-box 主内核时，可在多核设置的“OpenVPN / SSR / Mieru”行指定 Mihomo 副内核。
- 节点切换和智能候选按实际委托计划放行原文节点，排除端口冲突、链路占用及超出委托上限的节点。
- Mihomo 副内核的原文代理链引用按内部节点标签重写；改名不破坏原始引用，悬空、重名歧义和循环引用会给出错误而非静默直连。
- 首页仪表值采用单行省略、订阅名最多两行，减少轮询时布局跳动。
- 同步上游 macOS 图标资源；本轮上游未修改 Windows 图标。

## 保留的功能

保留按配置记忆最后选择节点、当前配置粘贴及 clone 命名、改名持久化和分享名称同步、右键编辑/分享/删除、圆点切换、单点测速、批量操作与拖拽排序。

## 使用与验证范围

OpenVPN 原文支持不等于所有版本的 Mihomo 都支持该协议；最终配置需通过所安装内核的启动前校验。原文节点暂不提供不完整的表单编辑或通用 URI 分享。Xray 无真实延迟接口，仍使用 TCP Ping 或切换内核。

本版本的 Rust 单测、订阅解析集成测试、前端回归、浏览器侧栏回归及 Windows 安装包/便携包构建在 GitHub Actions 执行。新增网络协议的实际连通性仍取决于内核版本、服务端与用户配置，不将配置生成测试当作真实联网结果。本次不自动替换本地客户端。
