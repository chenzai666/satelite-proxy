# Satelite 1.0.46

本版本继续整合上游正式版 1.0.46，并保留本分支的系统代理、DNS/IPv4、UWP、原生 Mihomo 分流与节点交互定制。

## 本次更新

### 2026-10-23 代理与直连流量分开统计

- 概览“流量统计”同时展示代理、直连和合计，各自列出实时上下行速度与本次累计；未识别流量单列“未分类”，缺分类数据显示“—”，不假装为零。
- Xray 一次读取出站计数并拆分；sing-box/Mihomo 按实际连接路径做保守采样累计，漏采短连接、未知路径和不一致增量留在未分类。分类与总量对账，不用“总量减直连”冒充代理。
- 分类在后端按内核会话维护，连接关闭或历史裁剪不丢已计流量；停止速度归零，新启动/切换内核重置，迟到的旧会话回包继续由原会话校验拦截。未知自写配置不猜测出站类型，多核不重复叠加。
- 保持1.0.46。补充Rust分类/对账/回退/上限回归、Node数据处理及浅深色/窄卡/缩放浏览器检查；客户端构建和Rust/浏览器验证仍在GitHub Actions执行，不替换本地运行客户端。

### 2026-10-20 二维码导入与 UUID 生成

- 配置页增加“扫描二维码”菜单：Windows 屏幕扫描（Ctrl+S）和本地图片扫描。保留现有导入流程，识别后只填入导入表单，确认后才保存；支持节点分享、HTTP/HTTPS 订阅及已有的一键订阅链接。
- 屏幕扫描覆盖虚拟桌面，临时隐藏主窗口后恢复；截图仅在内存中识别，不落盘、不上传、不写日志或剪贴板。图片上限16MB/3200万像素，后台Worker识别反色和大屏小码，失败可重试；非Windows使用图片入口。
- VLESS、VMess、TUIC 的 UUID 输入框旁增加“生成”按钮，使用 Web Crypto 随机 UUID v4。只有点击才修改草稿，保存/禁用状态保持一致，生成不会提交表单。
- 补充像素识别、快捷键/危险内容过滤、UUID单测、真实导入页面浏览器回归及CI桌面捕获回归。版本保持1.0.46，云端验证后覆盖同版本两包，不自动替换本地运行客户端。

### 2026-10-18 Xray 模式跨内核测速修复

- 修复 TUIC、AnyTLS 仍被交给 Xray 测试、随后统一显示 timeout 的问题。独立测速按节点能力委托 sing-box，Hysteria2 的混淆及跳过证书校验参数也能保留；普通可完整处理的节点继续由 Xray 测试。
- 接通已有“UDP 节点兼容模式”，无需新开关。TUIC 缺省补充 h3，开关仅对 Hysteria2/TUIC 应用跳过证书校验；AnyTLS 沿用节点自身 TLS 设置。仅修改临时节点副本，不改订阅和正在运行的主代理。
- 延迟状态区分协议不支持、缺少内核、配置错误、TLS 错误、连接失败、HTTP 异常响应与实际超时；安全错误摘要持久化，TCP Ping 不覆盖真实延迟的成功或失败结果。
- 继续保持 loopback 认证、stdin 配置、并发上限及自有进程清理，不切换主节点、系统代理或 TUN。新增三种协议的 CI 真实 sing-box 服务端测试及前端错误状态回归；版本保持 1.0.46，云端验证后覆盖原 Release 两包，不自动替换运行中的本地客户端。

### 2026-10-16 Xray 真实延迟测试

- 恢复专业/简洁节点页的 Xray 单点、分组和批量真实延迟入口，主代理关闭时也可测试，无需切换节点或内核。
- 复用 Xray 出站生成逻辑，使用独立、仅本机且带认证的临时 HTTP 入站；配置走标准输入，不修改活动配置、系统代理或 TUN。每轮并发最多 4 个进程，结束回收；错误不输出节点凭据。
- 新增 `xray_http` 结果类型，逐节点回传并保存；TCP Ping 不覆盖真实代理延迟。探测仅接受 2xx，不以端口通或重定向冒充代理成功。
- 增加浏览器入口回归及真实 Xray + 本地 SOCKS 模拟节点的 HTTP 成功/失败和进程清理验证；客户端构建与 Rust/浏览器测试继续在 Actions 执行，版本保持 1.0.46。

### 2026-10-14 Mihomo 策略组与模板

- 补齐专业/简洁节点管理与实时策略组选点联动：圆点/高亮和“选中组”来源跟随嵌套/自动组的最终节点；不再显示旧独立节点选择。停止、直连、读取失败和迟到回包不会恢复旧高亮，批量操作选中状态独立。

- 专业和简洁模式的节点页默认策略组，在组内选点；原节点编辑、分享、测速、删除和排序保留在“节点管理”标签，禁用直接切点。概览提供策略组导航入口。
- 策略组支持空白处拖拽排序并持久保存，只改变展示顺序；规则、全局、直连分别显示规则组、单个 GLOBAL、无选点组。
- 新普通订阅默认使用用户 `new_config.ini` 模板，保留其 18 个真实策略组、规则优先级和“🐟 其他域名” FINAL 出口；已有订阅显式选择后才应用。混合启用时共用模板和全部启用节点。
- 增加可编辑 URL/INI/基础 YAML，拉取后显式保存才生效，失败保留原配置。DNS 采用用户给出的 IPv4/FakeIP/直连及 DoH fallback 覆写，海外 fallback 经代理；入口保留 mixed2080，不增加7890/7891。默认 LAN/DNS 局域网监听范围见 README。
- 增加模板编译与存储回归、真实策略组页面拖拽/选点/保存测试及 Mihomo 三种模式配置校验；通过 Actions 构建后覆盖同版本 Release。

- 接入 Clash YAML、官方 `sudoku://` 短链与 Base64 订阅，节点不再因未知协议被跳过。
- 支持手动添加、编辑、分享/二维码和节点页复制粘贴，保留 HTTPMask、自定义表、加密、下行及复用参数。高级参数采用可编辑 JSON；分享扩展字段的外部兼容范围见 README。
- Mihomo 主内核直接使用；sing-box 主内核下可开启多核模式并将 SudoKu 指定到 Mihomo 副内核，保留原节点标签和分流引用。sing-box/Xray 无原生官方 SudoKu 出站，能力报告与提示保持一致。
- 手动选择 SudoKu 时，没有有效副核委托则自动切换到 Mihomo；已有有效委托则保持 sing-box 主核。后台智能选路不自动切主核，Mihomo 需先下载。
- 新增解析、编辑/分享往返、默认值兼容、错误脱敏、委托路径及真实 Mihomo 主/副配置校验。版本保持 1.0.46，由 Actions 构建并覆盖同版本 Release。

## 保留的功能

保留按配置记忆最后选择节点、当前配置粘贴及 clone 命名、改名持久化和分享名称同步、右键编辑/分享/删除、圆点切换、单点测速、批量操作与拖拽排序。

## 使用与验证范围

OpenVPN 原文支持不等于所有版本的 Mihomo 都支持该协议；最终配置需通过所安装内核的启动前校验。原文节点暂不提供不完整的表单编辑或通用 URI 分享。Xray 无 Clash 延迟 API，但生成配置的节点现可通过独立 Xray 进程测试真实 HTTP 延迟；TCP Ping 仍是单独的端口可达性测试。

本版本的 Rust 单测、订阅解析集成测试、前端回归、浏览器侧栏回归及 Windows 安装包/便携包构建在 GitHub Actions 执行。新增网络协议的实际连通性仍取决于内核版本、服务端与用户配置，不将配置生成测试当作真实联网结果。本次不自动替换本地客户端。
