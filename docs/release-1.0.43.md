# Satelite 1.0.43

## 本次更新

- 同步上游正式版至 1.0.43，采用冰蓝土星应用图标及 macOS 专用图标源；新增可选的经典土星托盘样式，默认样式不变。
- Windows 标题栏图标按显示缩放加载清晰尺寸；托盘左键唤起主窗口，右键仍显示菜单。
- 设置页加入默认关闭的 sing-box 和 Xray TLS ClientHello 分片开关。Xray 副内核也跟随 Xray 开关；Mihomo 不适用。
- 修正 VLESS 订阅中的未知 `packet_encoding` 值，避免生成无法加载的配置；缩短同权限启动时的端口残留等待。
- TUN 与副内核同时使用时，优先让副内核自身连接直连，避免回环。对节点 IP 字面量另有直连兜底，访问同一 IP 的其他流量也可能受影响。
- 保留本分支的节点编辑/分享/排序、订阅失败回退代理、原生 Mihomo 策略组、UWP 回环及 DNS/IPv4 定制。

## 整合边界

本次未直接移植上游允许同一 URL 重复订阅及节点身份迁移。该改动会影响本分支既有订阅去重、节点覆盖、排序和规则引用，需要单独设计数据迁移和回归。上游节点卡片徽标与订阅 ID 展示也未覆盖本分支节点页面。

## 验证

以本版本标签对应的 GitHub Actions 成功任务和 Release 两份 Windows x64 资产为准；工作流执行版本一致性、TypeScript、Rust 测试和客户端构建。macOS/Linux 实机、真实节点连通性与 TLS 分片效果不在 Windows 自动化验证范围内。
