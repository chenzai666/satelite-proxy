## 本次额外修复

规则页专用样式曾覆盖 max-height 为 none、overflow 为 visible，导致左侧随页面滚动。
现在 useRulesSidebarHeight 按实际可视空间计算高度，.ruleset-scroll 为独立滚动区；固定头部、菜单 portal、拖拽坐标缩放和内部自动滚动配套处理。

自动化测试使用隔离的浏览器夹具验证 1/1.5/2 倍缩放下侧栏高度、右侧位置不变、菜单/子菜单可操作和拖拽排序，不接触用户订阅或正在运行的代理。
