# Satelite 首页完整设计方案

## 一、首页目标

首页承担 5 个核心任务：

1. **显示当前代理是否运行**
2. **突出当前节点与连接状态**
3. **提供高频快捷操作**
4. **展示关键运行数据**
5. **作为其他功能页的总入口**

首页的重点不是堆设置项，而是让用户一眼看到：

* 当前开没开
* 连接到了哪里
* 延迟怎么样
* 当前流量情况
* 系统代理 / TUN 状态
* 规则模式
* 当前连接是否正常

所以首页设计应该偏向：

* **状态总览**
* **快速控制**
* **轻量监控**
* **低学习成本**

# 二、首页信息架构

首页建议分成 4 个区域：

```text
1. 顶部导航栏
2. 首屏状态区
3. 状态卡片区
4. 底部摘要 / 快速连接列表
```

对应结构：

```text
┌──────────────────────────────────────────────┐
│ 顶部导航                                     │
├──────────────────────────────────────────────┤
│ 左：连接球体 │ 中：连接状态与节点 │ 右：Quick Controls │
├──────────────────────────────────────────────┤
│ 状态卡片 1 / 2 / 3                           │
│ 状态卡片 4 / 5 / 6                           │
├──────────────────────────────────────────────┤
```

# 三、整体布局

## 1. 画布规格

适合 macOS 桌面应用窗口：

* 推荐窗口宽度：**1320–1440 px**
* 推荐窗口高度：**860–920 px**
* 页面内容宽度：**1240–1320 px**
* 页面左右内边距：**40 px**
* 内容模块间距：**16 px / 20 px / 24 px**
* 主窗口圆角：**20–24 px**

## 2. 栅格

推荐 **12 栏栅格**，首页按三段式首屏 + 六卡片布局组织。

### 首屏区

* 左：3 栏
* 中：5 栏
* 右：4 栏

### 卡片区

* 三列两行
* 每张卡片等宽
* 卡片高度统一

# 四、顶部导航栏设计

## 1. 导航目标

顶部导航负责：

* 品牌识别
* 一级页面切换
* 全局运行状态显示

## 2. 导航内容

建议导航如下：

```text
Logo / SATELITE
Overview
Nodes
Traffic
Profiles
Settings
● Connected
```

## 3. 导航布局

```text
┌────────────────────────────────────────────────────────────┐
│  ◇ SATELITE   [Overview] Nodes Traffic Profiles Settings  ● Connected │
└────────────────────────────────────────────────────────────┘
```

## 4. 样式建议

* 导航整体做成**悬浮胶囊**
* 背景：浅色磨砂卡片
* 当前页：深色胶囊高亮
* 状态点：

  * 绿色：Connected / Running
  * 灰色：Stopped
  * 黄色：Switching
  * 红色：Error

## 5. 导航尺寸

* 高度：**52 px**
* 圆角：**26 px**
* 内边距：**12 px 16 px**
* 导航项水平间距：**24 px**
* Logo 区域宽度：**120–140 px**

# 五、首屏状态区设计

这是首页最核心区域。

---

## A. 左侧：连接球体 / 主视觉

### 1. 作用

让首页有品牌辨识度，同时承担连接状态可视化。

### 2. 视觉形式

一个“卫星 / 轨道 / 节点”风格的球体组件：

* 中心为发光球体
* 外圈有一层轨道环
* 连接状态开启时有轻微呼吸光
* 外圈小点缓慢移动
* 当前节点国家可用颜色或小旗帜点缀
* 断开时球体变灰

### 3. 尺寸建议

* 外框：**220 × 220 px**
* 球体本身：**108–124 px**
* 外轨道半径：**84–96 px**

### 4. 状态表现

#### Connected

* 球体：绿色 / 青绿色
* 光晕：轻微扩散
* 小点：缓慢移动

#### Switching

* 外轨道扫描动画
* 球体亮度脉冲

#### Stopped

* 灰绿色 / 灰色
* 无动画

#### Error

* 球体边缘带少量暖红色提示

---

## B. 中间：连接状态信息区

### 1. 作用

清晰展示当前连接核心信息。

### 2. 内容结构

建议为：

```text
RUNNING · SING-BOX 1.13.15

🇸🇬 新加坡专线 04
BGP · 流媒体 · Premium

模式：Rule
端口：mixed :2080
延迟：23 ms

[ 停止代理 ] [ 切换节点⌄ ] [ 更多 ]
```

### 3. 设计重点

#### 状态标签行

内容：

* RUNNING
* SING-BOX 版本
* 当前子状态，例如 Downloading / Idle / Switching

建议样式：

* 使用小号等宽字
* 浅灰 + 状态绿点
* 字号 12–13 px

#### 节点标题

建议拆分成两级：

**主标题**

```text
🇸🇬 新加坡专线 04
```

**副标签**

```text
BGP · 流媒体 · Premium
```

不建议把所有信息都塞在一个超长标题里。

#### 运行信息行

建议用三段式：

```text
Rule Mode · mixed:2080 · 23 ms
```

或者做成三个小标签：

```text
[ Rule ] [ mixed:2080 ] [ 23 ms ]
```

### 4. 按钮设计

首页主操作建议保留三个：

#### 主按钮

* **停止代理** / **启动代理**
* 宽度：140–156 px
* 实心按钮
* 状态开启时为暖红 / 深橙边框浅填充
* 状态关闭时为绿色实心

#### 次按钮

* **切换节点**
* 胶囊描边按钮
* 点击弹出节点切换菜单

#### 更多按钮

* 三点按钮
* 菜单内容：

  * 重启核心
  * 复制环境变量
  * 打开日志
  * 导出配置
  * 打开配置目录

### 5. 尺寸建议

* 状态区宽度：**420–520 px**
* 主标题字号：**28–34 px**
* 副信息字号：**14–16 px**
* 按钮高度：**44 px**
* 按钮间距：**12 px**

---

## C. 右侧：Quick Controls

你提的这个位置是合理的。

### 1. 作用

首页右侧直接放高频控制项，用户不用往下找。

### 2. 内容结构

建议只放高频控制：

```text
QUICK CONTROLS

Routing
[ Rule ] [ Global ] [ Direct ]

System Proxy
HTTP / HTTPS / SOCKS
[ ON/OFF ]

TUN Mode
System-wide traffic capture
[ ON/OFF ]

Advanced Settings →
```

### 3. 交互说明

#### Routing

三段式切换器：

* Rule
* Global
* Direct

当前选中项为深色胶囊。

#### System Proxy

* 一个主开关
* 开启时状态字为 `Enabled`
* 说明文字显示使用协议：

  * HTTP / HTTPS / SOCKS

#### TUN Mode

* 一个主开关
* 说明为：

  * System-wide traffic capture
  * 或 Virtual Interface Capture

#### Advanced Settings

点击跳转到 Settings > Network / DNS / TUN 页面。

### 4. 尺寸建议

* 卡片宽度：**300–340 px**
* 卡片高度：**220–250 px**
* 内边距：**20–22 px**
* 组件间距：**16 px**

# 六、状态卡片区设计

首屏下面建议做 **6 张卡片**，三列两行。

原因：

* 信息更完整
* 留白更均衡
* 比 8 张更紧凑
* 更适合中文内容

---

## 卡片区布局

```text
┌ Core Status ─────┐ ┌ Active Node ─────┐ ┌ Traffic ─────────┐
└──────────────────┘ └──────────────────┘ └──────────────────┘

┌ Connections ─────┐ ┌ Routing Stats ───┐ ┌ Subscription ────┐
└──────────────────┘ └──────────────────┘ └──────────────────┘
```

---

## 1. Core Status 卡片

### 作用

展示 sing-box 核心运行状态。

### 内容建议

```text
CORE STATUS                      ONLINE

Running
sing-box is active

Uptime       2h 48m 16s
Version      1.13.15
Mode         Rule
```

### 设计说明

* 这里不建议放“100”这种抽象评分。
* 用户更关心是否运行、运行多久、核心版本。
* 可增加一个小状态点。

---

## 2. Active Node 卡片

### 作用

展示当前出站节点摘要。

### 内容建议

```text
ACTIVE NODE                   RULE

🇸🇬 新加坡专线 04
BGP · Streaming

Latency      23 ms
Protocol     VLESS + Reality
Provider     Premium
```

### 交互

点击卡片进入 Nodes 页面，并自动聚焦当前节点。

---

## 3. Traffic 卡片

### 作用

展示实时流量与累计流量。

### 内容建议

```text
TRAFFIC

↓ 12.4 KB/s
↑ 3.7 KB/s

Today        512 MB
Total        1.2 TB
```

### 增强项

卡片底部放一条轻量 sparkline 趋势图。

---

## 4. Connections 卡片

### 作用

展示当前连接数与连接质量。

### 内容建议

```text
CONNECTIONS

9 Active

TCP          7
UDP          2
Peak         18
```

### 可选增强

显示一个小标签：

```text
Stable
```

---

## 5. Routing Stats 卡片

### 作用

展示规则模式命中统计。

### 内容建议

```text
ROUTING STATS                RULE

Direct       1,286
Proxy        3,482
Block        283

Last Refresh  10s ago
```

### 意义

这张卡能让“Rule 模式”变得更有可读性。

---

## 6. Subscription 卡片

### 作用

展示订阅状态和配额。

### 内容建议

```text
SUBSCRIPTION                 ACTIVE

Last Update   1h 12m ago
Expires       in 24 days
Quota         78%

Profiles      4
Nodes         55
```

### 交互

点击进入 Profiles 页面。

# 十一、状态定义

首页至少要支持以下状态：

## 1. 已连接

* 顶部状态点绿色
* 球体发光
* 主按钮：停止代理

## 2. 未连接

* 顶部状态点灰色
* 球体变灰
* 主标题显示 `Disconnected`
* 主按钮：启动代理

## 3. 切换中

* 顶部状态点黄色
* 节点信息可显示 `Switching...`
* 主按钮禁用
* 球体轨道动画增强

## 4. 错误

* 顶部状态点红色
* 标题下显示简短错误描述
* 主按钮变为 `重试`
* Quick Controls 仍保留可操作

# 十二、交互建议

## 首页高频操作

首页可直接完成：

* 启动 / 停止代理
* 切换节点
* 切换出站模式
* 开关系统代理
* 开关 TUN
* 查看当前连接摘要

## 交互细节

### Hover

* 卡片 hover 时轻微上浮 1px
* 边框略加深
* 可点击卡片显示箭头或高亮

### Click

* 节点卡点击进入 Nodes
* 订阅卡点击进入 Profiles
* Traffic 卡点击进入 Traffic
* Routing Stats 卡点击进入 Analyze / Rules

### 动效

* 统一 180–240ms
* 使用平滑淡入、透明度变化、轻微缩放
* 球体动画保持慢节奏

# 十四、最终建议

这套首页的核心方向可以总结成一句话：

**用一个有品牌感的状态首屏，承载代理软件最重要的连接信息和高频操作，再用简洁的数据卡片补足运行感知。**

它会比你现在这版更好的一点主要体现在：

* 页面重心更稳定
* 空白利用率更高
* 状态和控制聚合得更自然
* 首页更像一个“代理控制台”
* 视觉上仍然保持你想要的高级感和轻科技感
