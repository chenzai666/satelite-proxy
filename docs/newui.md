该 UI 采用**单页应用式布局**，核心结构围绕「底部主导航 + 内容页面 + 卡片化功能模块」展开。整体信息架构偏向移动端代理工具，但页面结构也适合桌面端窗口。

## 1. 全局布局结构

### 页面层级

```
App Shell
│
├── 顶部区域
│   ├── 页面标题 / 品牌区域
│   └── 页面辅助操作
│
├── 主内容区域
│   ├── 状态展示
│   ├── 功能卡片
│   ├── 列表模块
│   └── 设置项
│
└── 底部固定导航栏
    ├── Connect
    ├── Servers
    ├── Logs
    └── Settings
```

特点：

* 底部导航固定存在，不随页面滚动。
* 页面内容区域独立滚动。
* 不采用侧边栏，主要依靠底部 Tab 切换一级功能。
* 一级页面之间保持相同布局框架。

---

## 顶部区域

内容：

* 应用 Logo
* 应用名称

作用：

* 品牌识别
* 当前模块入口

布局：

* 居中排列
* 高度固定

---

## 核心连接区域

页面中心为主要操作区域：

```
        Power Button

        Connected
```

交互：

* 点击中心按钮：

状态切换：

```
Disconnected
      ↓
Connecting
      ↓
Connected
```

按钮承担主要任务：

* 开启代理
* 停止代理
* 显示当前状态

属于页面唯一主操作。

---

## 当前节点信息

结构：

```
[协议类型]  节点名称  延迟
```

例如：

```

```

布局：

横向信息条。

内容：

* 协议标签
* 当前服务器
* 延迟

交互：

点击进入：

* Server 页面
* 节点切换

---

## 本地代理状态

结构：

```
Proxy on 127.0.0.1:2080     运行时间
```

作用：

展示运行状态：

* 本地端口
* 已运行时间

属于状态信息，不提供复杂操作。

---

## 流量统计

结构：

```
↑ 上传速度
↓ 下载速度
累计流量
```

单卡片横向排列：

```
Upload | Download | Total
```

用于快速查看：

* 当前速度
* 总消耗

# 6. 信息优先级设计

页面优先级：

## Connect

```
1. 当前是否连接
2. 当前节点
3. 当前运行状态
4. 流量
```

---

## Servers

```
1. 当前节点
2. 节点列表
3. 延迟
4. 节点管理
```

---

## Settings

```
1. 常用开关
2. 代理模式
3. DNS
4. 系统行为
5. 高级配置
```

---

整体属于：

**「控制中心型代理客户端布局」**

核心交互路径：

```
打开软件
 ↓
看到连接状态
 ↓
快速切换节点
 ↓
查看运行情况
 ↓
进入设置调整行为
```

适合作为 sing-box / mihomo 类代理软件的主界面信息架构。
