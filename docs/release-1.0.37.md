# Satelite 1.0.37

## 本次更新

- Xray 不再尝试加载已移除的旧版 Shadowsocks 流加密；手动选择此类节点时由 sing-box 兼容处理，避免核心启动失败。
- Xray 在运行中手动切换节点会自动重启，使新节点立即生效。
- 修复刚停止核心后端口仍短暂不可绑定的竞态，仅对明确的端口占用瞬态错误重试一次，不掩盖配置错误。
- 节点、概览和简洁节点页实时同步延迟；真实代理链路延迟优先于 TCP Ping，避免 TCP 连通掩盖代理链路失败。
- Xray 不再把 TCP Ping 伪装成真实延迟；可改用 Ping 测试或切换 sing-box/Mihomo。
- 订阅自动更新支持自定义分钟间隔，并校验正整数输入。
- 延续规则页左右独立滚动、批量规则输入校验、XHTTP 分享/编辑往返和节点拖拽等本分支修复。

## 上游整合（1.0.33–1.0.37）

- 智能切换增加出口巡检和候选真实代理路径验证，不再仅凭 TCP ping 选择出口；确认失效后可以越过优化冷却进行恢复。
- 智能任务监督、非阻塞锁竞争处理、慢探测诊断，移除可能堵塞后台任务的同步控制台日志镜像。
- 设置页不再每次进入都请求三内核的最新版本；点击检查时查询，并在本次会话保留结果。分支的预发布版本信息保留。
- Xray v26 已移除的 h2/http 传输不再生成无效配置；XHTTP extra 支持 URI base64url/JSON 和 Clash YAML 输入。h2 节点仍可由兼容内核使用。
- 导航栏材质统一、macOS 图标更新；内核下载按版本复用缓存并在失败时退避重试。
- 1.0.36–1.0.37 的核心兼容、切节点重启、端口竞态、延迟同步、订阅间隔和 Xray 延迟语义已选择性整合。

## 保留与边界

- 保留本分支的原生 Mihomo 订阅策略组、节点拖拽/右键操作、UWP 回环、IPv4/DNS、代理状态同步和失败回滚。
- 不恢复赞助入口或 TUN 绕过检测提示；项目和更新地址仍指向 chenzai666 分支。
- 发布目标为 Windows x64 NSIS 安装包和便携 ZIP，默认仅内置 sing-box，Xray/Mihomo 按需下载。
- 不自动修改本机安装、代理或配置。升级前备份用户配置；本次版本基于上游最新正式 Release `v1.0.37` 构建。
- 上游 `v1.0.38` 目前只有版本 Tag、没有正式 Release，不作为本次正式版本依据；其图标与托盘资源也不覆盖本分支定制。
- Linux/macOS 打包与真实节点连通性不在此次 Windows 自动化验证范围内。

## 验证

版本一致性、TypeScript、确认弹窗、规则输入、浏览器侧栏几何与拖拽回归、Rust 单元测试及 Windows 剪贴板回归由构建流程检查。以成功的 GitHub Actions 任务和发布产物为准。
