# 代理链（sing-box）

代理链用于把一个规则集的流量依次经过两个或更多节点/节点池。它只由
sing-box 内核生成实际的 `detour` 链路；切换到 Xray 或 mihomo 时，引用
代理链的规则会安全回退到普通“代理”出口，避免生成无效配置或出现假
多跳。

## 使用方式

1. 在“设置 → 代理链”创建节点池：可固定选择节点，也可按节点名称关键
   词动态筛选。
2. 创建至少两跳的链路。列表从上到下就是实际顺序：第一跳是入口，最后
   一跳是对外出口。
3. 在“规则”中把本地或远程规则集的出口策略选择为“代理链”，再选择已
   创建的链路。
4. 启动 sing-box 后，可在链路卡片中执行诊断，分别查看每跳独立延迟、
   经过前序跳后的延迟，以及最终出口的 ip.sb 校验结果。

## 生成原则

- 固定节点池保存节点 ID，因此订阅刷新后仍能稳定定位同一个节点；被删
  除的节点会使链路失效，规则会回退到普通代理出口。
- 关键词节点池在每次生成配置时重新匹配当前订阅节点，并按已有延迟优先
  排列。
- 非首跳的节点池会生成带 `detour` 的链路专用副本，不能复用普通节点池
  的无 detour 出站；这保证每一跳都真正经过前序跳。
- 不能删除仍被规则集引用的链路，也不能删除被链路引用的节点池。

## 诊断限制

诊断依赖 sing-box 的 Clash 兼容 API 和仅监听本机的临时诊断入口；不会
开放额外的局域网端口，也不会修改系统代理设置。内核未运行、链路包含
失效跳，或出口禁止 ip.sb 时，页面会显示具体错误而不是将其误报为链路
正常。
