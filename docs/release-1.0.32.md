# Satelite 1.0.32

## 本次更新

- 整合上游 1.0.31–1.0.32，应用、安装包、便携包与发布标签同步为 1.0.32。
- 专业/简洁模式支持放大窗口、界面等比缩放及各自尺寸记忆；保留 Windows 任务栏图标修复，节点拖拽适配界面缩放。
- 新增 MASQUE 协议的 Clash 订阅和手动节点导入，Mihomo 原生支持；sing-box 主内核可显式委托给 Mihomo，未委托时不冒充支持。
- MASQUE 暂不生成分享链接或二维码，点击分享会说明应使用 Clash YAML，不输出凭据或伪造 URI。
- 修复 HTTP/HTTPS 节点使用默认端口 80/443 时被误报为“缺少端口”，覆盖省略端口、显式默认端口和分享后重新导入。
- 多核模式从 Xray 单副内核扩展为 Xray + Mihomo：独立端口、日志、看门狗；副内核启动失败整体回滚。保留分支节点选择、订阅原生策略组、UWP 和确认安全修复。
- Windows 系统代理读取及托盘复制改用原生 API，去除控制台进程闪现；补齐剪贴板有效窗口所有者，支持 Unicode 文本。
- 更新应用图标，合入 Linux WebKit DMA-BUF 启动兼容修复。当前分支仅发布并验证 Windows 包，不宣称 Linux/macOS 实机验证完成。
