# Satelite 1.0.44

## 本次更新

- 同步上游正式版 1.0.44：Windows 程序、安装包和任务栏图标采用与 macOS 相同的手调源图，保留小尺寸清晰度优化。
- 按专业/简洁模式保存窗口大小与位置，冷启动及托盘重建恢复原位置，兼容旧版只保存尺寸的数据。
- 拔除显示器或调整分辨率后，检查窗口标题栏可达性，无法操作时自动居中；普通托盘隐藏后唤醒也会检查。
- 包含 1.0.43 同版本修复：Ctrl+C 复制标准分享链接，Ctrl+V 向当前配置追加节点；重复节点使用 -clone、-clone-2，不新建剪贴板配置。
- 本地追加节点保留独立 ID，订阅刷新时保留；恢复本地编辑记录，改名按配置和节点隔离，分享链接及二维码使用有效名称。
- 分享 URI 正确保留空格、加号、中文名称及凭据；不改变节点连接参数。
- 保留本分支原生 Mihomo 策略组、节点编辑/排序、UWP 回环和 DNS/IPv4 定制。

## 验证及边界

Windows 安装包和便携包仅在 GitHub Actions 测试及构建成功后发布，不在本地构建。新增窗口布局读取与标题栏可达性测试；不同 DPI 多显示器与 macOS/Linux 行为需实机验证。

上游同 URL 多订阅和节点身份迁移继续暂缓，避免破坏已有本地覆盖、排序和规则引用。升级前建议备份数据；更新后需退出旧实例并重新启动。
