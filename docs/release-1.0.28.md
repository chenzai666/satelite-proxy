# Satelite 1.0.28

## 确认弹窗修复（2026-09-12）

- 修复 `Command plugin:dialog|confirm not allowed by ACL`：统一使用插件公开的异步确认接口，不增加 ACL 权限。
- 修复把 Promise 当作布尔值造成的确认绕过：节点/订阅/规则/Hosts 删除、记录清空、内核恢复与未保存编辑确认均等待用户结果。
- 弹窗失败或重复点击时不执行操作；新增模拟 IPC 和全库调用检查。
- 本轮不宣称解决间歇性订阅导入报错或漏节点；这条日志本身指向确认弹窗而非订阅解析器。

## 智能切换连接保护（2026-09-11 第三次构建）

- 修复智能优选节点时误清理全部连接：普通优化保留已有会话，故障切换才按用户的“切换后关闭连接”设置清理。
- 后台智能策略组调整不再触发全局断连，避免影响其他分组的下载、游戏和长连接。
- 手动切换节点/策略组的清理设置、切换结果校验、Xray 不兼容节点自动交给 sing-box 的行为不变。
- 增加两种内核下共 12 个切换场景的本地模拟接口回归检查，由 GitHub Actions 执行。

## 历史遗漏补齐（2026-09-11 第二次构建）

- 修复 1.0.11 遗漏的 Xray DNS 分类/回退及 Mihomo 跨池 fallback，统一国内 DNS 地址来源。
- 补入 1.0.10 代理链图形编辑器、节点池菜单及首屏视觉偏好缓存。
- 补齐 1.0.24 的委托节点标记布局。
- 补齐 macOS 授权失败诊断、PTY 超时清理、下载脚本执行权限和跨架构自检容错。
- 修正 GeoSite.dat 打包清单大小写及 Intel macOS Mihomo compatible 预取路径。
- 保留订阅原生策略组、IPv4 设置、右键编辑/删除/分享、UWP 功能；不恢复 TUN 感知提示。

历史范围、保留差异和验证边界见 `docs/upstream-integration-audit.md`。

本次同步上游应用版本，并按本分支的 Windows、多内核和订阅策略实现整合功能。

- 移除首页“疑似绕过系统代理 / 开启 TUN”提示、相关定时采样和后端检测命令；保留 TUN 开关及 UWP 回环功能。
- 远程订阅支持自定义 User-Agent，添加、编辑和自动刷新统一使用；保留本分支的短链重定向、认证代理通道及直连失败回退。
- 新增节点详情，复用原有右键菜单与卡片菜单，保留编辑、删除、分享和单点测速。
- 支持自定义远程 DoH，应用到三内核生成配置和 DNS 诊断；空列表保留内置默认。
- 内核下载进度跨页面显示，内核卡显示安装时间；下载连接超时收紧，并支持启动前读取已有代理。
- Mihomo amd64 选择 compatible 包，改善旧 CPU 兼容性。
- 合并 macOS 同类型内核升级时保持既有 TUN 授权的修复。

本分支仍采用现有 Windows 安装版和便携版构建流程，没有引入上游三内核强制捆绑、仓库内 geodata 二进制快照及第三方内核下载镜像。内核文件从官方 Release 获取。

## 验证

Windows 安装版、便携版和 Rust 单元测试通过 GitHub Actions 执行。下载对应版本的安装包覆盖安装可保留原有订阅和设置。
