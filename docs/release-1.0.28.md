## 节点手动排序（2026-09-12）

- 节点列表/网格支持普通点击选中、拖动调序，圆点切节点、延迟按钮测速保持不变。
- 松开后保存为默认顺序，重开页面/客户端保留；刷新后仍存在的节点保序，新节点追加。
- 支持搜索、收藏筛选下调序，保留隐藏节点；分组模式限定组内移动，跨组请选默认平铺。
- 拖动含落点指示、边缘自动滚动、Esc/失焦取消；只改展示顺序，不重启代理。

## 确认弹窗修复（2026-09-12）

- 修复 `Command plugin:dialog|confirm not allowed by ACL`：统一使用插件公开的异步确认接口，不增加 ACL 权限。
- 修复把 Promise 当作布尔值造成的确认绕过：节点/订阅/规则/Hosts 删除、记录清空、内核恢复与未保存编辑确认均等待用户结果。
- 弹窗失败或重复点击时不执行操作；新增模拟 IPC 和全库调用检查。
- 本轮不宣称解决间歇性订阅导入报错或漏节点；这条日志本身指向确认弹窗而非订阅解析器。

## 智能切换连接保护（2026-09-11 第三次构建）

- 修复智能优选节点时误清理全部连接：普通优化保留已有会话，故障切换才按用户的“切换后关闭连接”设置清理。
- 后台智能策略组调整不再触发全局断连，避免影响其他分组的下载、游戏和长连接。
- 手动切换节点/策略组的清理设置、切换结果校验、Xray 不兼容节点自动交给 sing-box 的行为不变。
- 增加两种内核下共 12 个切换场景的本地模拟接口回归检查，由 GitHub Actions 执行。

本次同步上游应用版本，并按本分支的 Windows、多内核和订阅策略实现整合功能。

- 移除首页“疑似绕过系统代理 / 开启 TUN”提示、相关定时采样和后端检测命令；保留 TUN 开关及 UWP 回环功能。
