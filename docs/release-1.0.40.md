# Satelite 1.0.40

## 本次更新

- 修复设置页规则、代理链、多核模式和 DNS 等嵌入标签页在内容较短时仍出现空白滚动尾巴的问题。短内容按实际可见高度填充，长内容照常滚动。
- 补齐添加配置、手动节点字段、快捷菜单、错误恢复页等界面的英文文案；中英文托盘菜单可随界面语言切换刷新。
- 英文界面下将订阅提供的“长期有效”“永久有效”显示为英文，不修改订阅原始内容。
- 补入上游 v1.0.40 的笑脸土星应用图标（含 Windows 安装包、任务栏、macOS/Linux 尺寸）；托盘新增可选“土星”样式，现有默认样式不变。
- 保留本分支的节点编辑/分享/排序、订阅直连失败回退代理、Windows 主窗口图标重设、UWP 回环与 Mihomo 原生策略组。

## 整合范围

- 对照上游正式 Release v1.0.38、v1.0.39、v1.0.40 及其标签提交，选择性合入设置页滚动、界面翻译和图标改动。
- 应用图标采用上游 v1.0.40 资源；旧托盘样式继续可选。标签之后、尚未发布的上游提交不计入本次版本。
- 本分支 Windows x64 安装包默认内置 sing-box；Xray/Mihomo 按需下载。Linux/macOS 安装包和真实节点连通性不在本次 Windows 自动化验证范围内。

## 验证

以本版本标签对应的 GitHub Actions 成功任务和 Release 两份资产为准；版本一致性、TypeScript、界面回归、Rust 单元测试与 Windows 剪贴板回归均由工作流检查。
